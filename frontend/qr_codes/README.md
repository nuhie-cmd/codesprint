# Campus QR Codes

Each QR code represents a starting location in the campus navigation system.

QR Contents:

- main_block
- mechanical_block
- canteen
- cse_department
- cse_aiml_department
- is_department
- aiml_lab_1
- aiml_lab_2
- aiml_lab_3
- second_year_classroom
- third_year_classroom
- fourth_year_classroom

When scanned, the application should read the location ID and use it as the user's current position before calculating the shortest path.
